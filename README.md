# HireOS

HireOS is an AI-native hiring operating system project.

This repository contains the product, architecture, UI guideline, front-end prototype, and market/reference documents used to shape the HireOS concept.

## Contents

- `docs/hireos-prd-comprehensive.md` - comprehensive PRD with functions, scenarios, fields, statuses, business rules, AI boundaries, metrics, and acceptance criteria.
- `docs/mvp-gap-analysis.md` - assessment of the current prototype's gap to MVP.
- `docs/product-requirements.md` - lighter product requirements draft.
- `frontend-prototype/` - static HTML/CSS/JS prototype for the HireOS dashboard and module pages.
- `CONTEXT.md` - domain glossary for consistent HireOS vocabulary.
- `docs/HireOS 产品文档(1).md` - source product documentation.
- `docs/HireOS架构流程设计(1).md` - source architecture and workflow design.
- `docs/HireOS_UI_Design_Guideline(2).docx` - UI design guideline.
- `docs/Vietnam_AI_Hiring_OS_AI_Native_End_to_End_v0.4.pdf` - Vietnam AI hiring OS reference deck.
- `sources/` - read-only synced project reference materials.

## Status

Initial project repository created from the local HireOS project materials and expanded with the current MVP PRD and front-end prototype.
